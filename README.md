# منصة الوزارة لجمع البيانات — Ministry Data Collection Platform

منصة شبيهة بـ KoboToolbox مبنية بـ Next.js + Supabase، بواجهة عربية/إنجليزية متجاوبة (هاتف وحاسوب) ونظام صلاحيات.

## المزايا
- **بناء نماذج**: نص، رقم، تاريخ، قوائم اختيار، اختيار متعدد، صورة، موقع GPS
- **جمع بيانات ميداني** من الهاتف أو الحاسوب
- **صلاحيات**: مدير (يدير كل شيء) / مشرف / مستخدم (يعبّئ النماذج المتاحة له)
- **مراجعة الإدخالات** (قبول/رفض) وتصدير CSV
- **ثنائي اللغة** عربي (RTL) / إنجليزي مع تبديل فوري
- **هوية بصرية مركزية**: عدّل الألوان في `src/app/globals.css` والاسم/الشعار في `src/lib/branding.ts`

## التشغيل محلياً
```bash
cp .env.example .env.local
npm install
npm run dev
```

## ملاحظات
- **أول حساب يُسجَّل يصبح مديراً تلقائياً**، وبقية الحسابات "مستخدم".
- المستخدم يرى فقط نماذج المشاريع المضاف إليها (يديرها المدير من صفحة «المستخدمون»).
- قاعدة البيانات: Supabase مع سياسات أمان على مستوى الصفوف (RLS).

## تخصيص الهوية البصرية
1. ضع شعار الوزارة في `public/logo.svg`
2. عدّل الألوان في `src/app/globals.css` (متغيرات `--brand` وغيرها)
3. عدّل اسم الوزارة في `src/lib/branding.ts`

## الميزات المضافة (2026-08-15)
- **/map** خريطة حيّة للإدخالات (MapLibre) مع تصفية وتصدير GeoJSON.
- **/report** صفحة بلاغات مجتمعية عامة بلا حساب (موقع + صورة + وصف) → تدخل بحالة "قيد المراجعة".
- **/reports** مراجعة البلاغات للمدراء/المشرفين (تأكيد/إغلاق/رفض) على خريطة.
- **PWA**: تثبيت على الهاتف + عمل دون اتصال مع مزامنة تلقائية للإدخالات والصور.
- **PostGIS**: عمود `geom` يُملأ تلقائياً؛ عرضا `submissions_map` و`public_reports_map` جاهزان لـ QGIS — انظر `docs/QGIS.md`.

## نموذج الأدوار (محدَّث 2026-08-16)
- **مدير (admin):** لوحة تحكم لإدارة المستخدمين (تفعيل/إيقاف/حذف/ترقية)، ويرى كل الاستبيانات والإجابات والبلاغات العامة.
- **مستخدم (user):** أي حساب جديد. ينشئ استبيانات، ينشرها، ويشاركها برابط عام `/s/<token>` (+QR). يرى إجاباته فقط.
- **المجيب:** أي شخص يفتح الرابط — لا حساب. يمكن للمستخدم وضع **رمز دخول** لحصر الاستبيان بالباحثين، وطلب اسم/هاتف المجيب.
- الإجابات العامة تعمل دون اتصال (تُحفظ وتُرسل تلقائياً).
